\section{半正定矩阵的判据}

西尔维斯特判据（Sylvester Criterion）是一组利用主子式判断矩阵正定性的条件。

\begin{BoxProperty}[正定矩阵的西尔维斯特判据]
    设$\vb{A}\in\Symm^n$，$\vb{A}\succ\vb{0}$当且仅当$\vb{A}$的全部顺序主子式$>0$。
\end{BoxProperty}

\begin{BoxProperty}[负定矩阵的西尔维斯特判据]
    设$\vb{A}\in\Symm^n$，$\vb{A}\prec\vb{0}$当且仅当$\vb{A}$的奇次顺序主子式$<0$而偶次顺序主子式$>0$。
\end{BoxProperty}

顺序主子式是指一个矩阵从左上角向右下角组成的$1\times 1,\cdots,n\times n$的子矩阵的行列式，总共有$n$个，主子式则没有从左上角连续的要求，可以由任意的行和列组成，总共有$2^{n}-1$个。

\begin{BoxProperty}[半正定矩阵的西尔维斯特判据]
    设$\vb{A}\in\Symm^n$，$\vb{A}\succeq\vb{0}$当且仅当$\vb{A}$的全体主子式$\geq 0$。
\end{BoxProperty}

\begin{BoxProperty}[半负定矩阵的西尔维斯特判据]
    设$\vb{A}\in\Symm^n$，$\vb{A}\preceq\vb{0}$当且仅当$\vb{A}$的奇次主子式$\leq 0$且偶次主子式$\geq 0$。
\end{BoxProperty}

由此可见，判定正定或负定只要检查$n$个，判定半正定或半负定需要检查$2^{n}-1$个！

\begin{BoxProperty}[不定矩阵的判据]
    设$\vb{A}\in\Symm^n$，$\vb{A}\not\succeq\vb{0}$当且仅当满足以下任一条件：
    \begin{itemize}
        \item 存在两个不同阶的奇次顺序主子式符号不同。
        \item 存在某个偶次顺序主子式$<0$。
    \end{itemize}
\end{BoxProperty}

除此之外，如果$\vb{A}$已经是半正定矩阵，通过什么条件我可以确定$\vb{A}$是正定的呢？

\begin{BoxProperty}[半正定的等号成立条件]
    设$\vb{A}\in\Symm^n$，$\vb{A}$半正定，对于$\vb{x}\in\R^n$，$\vb{x}^T\vb{A}\vb{x}=0$当且仅当$\vb{A}\vb{x}=\vb{0}$。
\end{BoxProperty}

\begin{Proof}[\cref{ppt:半正定的等号成立条件}]
    充分性由$\vb{A}\vb{x}=\vb{0}$推出$\vb{x}^T\vb{A}\vb{x}=0$是显然的，现在证明必要性，由$\vb{x}^T\vb{A}\vb{x}=0$推出$\vb{A}\vb{x}=\vb{0}$。

    设$\vb{x},\vb{y}\in\R^n$，其中$\vb{x}$满足$\vb{x}^T\vb{A}\vb{x}=0$，构造关于$\lambda\in\R$的二次函数
    \begin{Equation}[半正定等号条件1]
        f(\lambda)=(\vb{x}+\lambda\vb{y})^T\vb{A}(\vb{x}+\lambda\vb{y})\geq 0
    \end{Equation}

    展开
    \begin{Equation}[半正定等号条件2]
        f(\lambda)=(\vb{y}^T\vb{A}\vb{y})\lambda^2+2(\vb{y}^T\vb{A}\vb{x})\lambda+(\vb{x}^T\vb{A}\vb{x})\geq 0
    \end{Equation}

    由于$f(\lambda)\geq 0$，其判别式必然$\leq 0$
    \begin{Equation}[半正定等号条件3]
        \Delta=4(\vb{y}^T\vb{A}\vb{x})^2-4(\vb{y}^T\vb{A}\vb{y})(\vb{x}^T\vb{A}\vb{x})\leq 0
    \end{Equation}

    已知$\vb{x}^T\vb{A}\vb{x}=0$，代入即得
    \begin{Equation}[半正定等号条件4]
        4(\vb{y}^T\vb{A}\vb{x})^2\leq 0
    \end{Equation}

    故$\vb{y}^T\vb{A}\vb{x}=0$需要对任意$\vb{y}\in\R^n$成立，这就证明了$\vb{A}\vb{x}=\vb{0}$。
\end{Proof}

由此可见，半正定矩阵的$\vb{x}^T\vb{A}\vb{x}\geq 0$中的等号$\vb{x}^T\vb{A}\vb{x}=0$仅当$\vb{x}\in\nullspace(\vb{A})$时成立，换言之，如果$\vb{A}$不存在$\nullspace(\vb{A})$，即$\vb{A}$非奇异，等号就排除了，那么半正定矩阵就一定是正定矩阵了！

\begin{BoxProperty}[半正定与正定的关系]
    设$\vb{A}\in\Symm^n$，$\vb{A}$半正定且非奇异，当且仅当$\vb{A}$正定。
\end{BoxProperty}
